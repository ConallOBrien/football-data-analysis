# Data Sources and Attribution

This project uses match information from the Soccer match event dataset, published on Figshare.

**Dataset collection:**

https://figshare.com/collections/Soccer_match_event_dataset/4415000/5

**Original research paper:**

Pappalardo et al. (2019), *A public data set of spatio-temporal match events in soccer competitions*.

https://doi.org/10.1038/s41597-019-0247-7

**Original data provider:** Wyscout.

## Modifications

The original JSON data is processed and transformed into simplified CSV files.

The processed files are not the original dataset files.
