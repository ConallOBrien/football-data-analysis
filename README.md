# football-data-analysis
A Python football data analysis using historical match data from the Wyscout Soccer Match Event Dataset

The project currently focuses on extracting match information, simplifying historical match results into CSV files, and generating football league tables.

## Current Features

- Extract match information from the original JSON dataset.
- Convert match data into simplified CSV format.
- Generate league tables from processed match results.
- Calculate basic league statistics, including points, wins, draws, losses and goal difference.
